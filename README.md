# קוד הבית — מדריך אורח ב‑QR

מדריך אורח דיגיטלי לדירות נופש. האורח סורק QR ומקבל עמוד מובייל עם כל מה שהוא צריך,
בעברית ובאנגלית. בעל הדירה מפסיק לענות על אותן שאלות בכל שעה.

**חי:** https://orr19988-dotcom.github.io/kod-habait/

---

## לקוח חדש — שלוש פקודות

```bash
# 1. צור properties/<id>.json  (הסכימה ב-SCHEMA.md)
py build.py
py make-qr.py --all https://orr19988-dotcom.github.io/kod-habait
git add . ; git commit -m "לקוח חדש" ; git push
```

זהו. נוצרו לו מדריך, יעד QR, קוד QR ומדבקה להדפסה.

## מה יוצר מה

| מקור — **עורכים** | נוצר — **לא נוגעים** |
|---|---|
| `properties/<id>.json` — תוכן הנכס | `g/<id>/` — מדריך האורח |
| `template.html` — העיצוב של כולם | `a/<id>/` — יעד ה‑QR |
| | `stickers/<id>.html` — מדבקה להדפסה |
| | `qr/<id>.svg` + `.png` — קודי ה‑QR |

`g/`, `a/`, `stickers/` נמחקים ונכתבים מחדש בכל `py build.py`.

## הפקודות

| פקודה | מה היא עושה |
|---|---|
| `py build.py` | בודק את כל הנכסים ובונה הכול |
| `py build.py --check` | בדיקה בלבד, בלי לכתוב |
| `py build.py --selftest` | מוודא שהבדיקה תופסת קובץ פגום |
| `py make-qr.py --all <בסיס>` | QR לכל הנכסים |
| `py make-qr.py <כתובת> <שם>` | QR בודד לכתובת כלשהי |
| `py make-qr.py --selftest` | בדיקה עצמית |

## איך משנים לאן QR מוביל

ה‑QR מצביע תמיד ל‑`a/<id>/`, לנצח. את היעד משנים בשורה אחת ב‑`a/<id>/index.html`:

```html
<meta http-equiv="refresh" content="0; url=../../g/<id>/">
```

דוחפים, ותוך דקה כל המדבקות שהודפסו מובילות למקום החדש. בלי להדפיס QR מחדש.

⚠️ אחרי שינוי יעד — לבדוק בטלפון **שלא פתח את הקישור קודם**. GitHub Pages שומר במטמון עד כ‑10 דקות.

## הערות

- **`a/demo/`** הוא קישור ישן שכבר נסרק ושותף. הוא מוביל ל‑`g/red-view/` ואינו נוצר על ידי `build.py`. לא למחוק.
- שני הנכסים בתיקייה הם **דוגמאות**. כל הפרטים מומצאים. מספרי החירום (100/101/102) אמיתיים.
- `sea-breeze` מכיל בכוונה רק חלק מהשדות — הוא ההוכחה שמקטע חסר פשוט לא מוצג.
- אין באתר אנליטיקה, עוגיות או איסוף מידע על האורחים.

## דרישות

Python 3 + `segno` (`py -m pip install segno`). זהו. אין node_modules ואין שלב בנייה חיצוני.
