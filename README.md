# קוד הבית — מדריך אורח ב‑QR

מדריך אורח דיגיטלי לדירות נופש. האורח סורק QR ומקבל עמוד מובייל עם כל מה שהוא צריך,
בעברית ובאנגלית. בעל הדירה מפסיק לענות על אותן שאלות בכל שעה.

## מבנה

```
a/demo/index.html       ← היעד של ה‑QR. שכבת הפניה בלבד.
g/red-view/index.html   ← מדריך האורח עצמו (נכס דוגמה)
make-qr.py              ← יוצר QR מקומית, בלי שירות חיצוני
```

## איך משנים לאן ה‑QR מוביל

עורכים **שורה אחת** ב‑`a/demo/index.html`:

```html
<meta http-equiv="refresh" content="0; url=../../g/red-view/">
```

דוחפים, ותוך דקה כל המדבקות שהודפסו מצביעות ליעד החדש. אין צורך להדפיס QR מחדש.

## איך מחליפים דירה

כל תוכן הנכס יושב באובייקט `P` בראש `g/red-view/index.html`, מסומן בהערה.
עורכים אותו ושומרים. שאר הקובץ לא נוגעים.

## יצירת QR

```bash
py make-qr.py https://orr19988-dotcom.github.io/kod-habait/a/demo/ red-view
```

נוצרים `red-view.svg` (להדפסה) ו‑`red-view.png` (לוואטסאפ).
בדיקה עצמית של הסקריפט: `py make-qr.py --selftest`

## הערה

`g/red-view/` הוא **נכס דוגמה**. כל הפרטים מומצאים — הטלפון, הכתובת וההמלצות.
מספרי החירום (100 / 101 / 102) אמיתיים.
